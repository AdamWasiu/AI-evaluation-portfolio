AI Evaluation & Data Annotation Portfolio

Professional Overview

I am an AI evaluation and data annotation specialist with experience assessing AI-generated visual content, checking instruction adherence, verifying text embedded in images, and evaluating multimodal outputs.

My work focuses on identifying quality issues, inconsistencies, potential hallucinations, and deviations from task guidelines. I value accuracy, careful reasoning, consistent application of evaluation criteria, and clear documentation of findings.

Core Skills

* AI-generated image evaluation and annotation
* Multimodal AI output assessment
* Instruction adherence and guideline compliance
* OCR and text-in-image verification
* Visual quality and artifact assessment
* Hallucination and inconsistency detection
* Research evaluation and fact-checking
* Reference-image comparison
* Identification and escalation of ambiguous or problematic cases

Evaluation Approach

My evaluation process emphasizes:

1. Instruction adherence: Checking whether an output satisfies the requested task and its constraints.
2. Visual quality: Examining image clarity, artifacts, anatomy, and other visual inconsistencies.
3. Text verification: Checking text appearing in images for accuracy and consistency with the task.
4. Evidence-based assessment: Comparing outputs against available references and task-specific criteria.
5. Quality control: Applying guidelines consistently and flagging uncertain cases when necessary.
